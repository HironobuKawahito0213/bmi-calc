# BMI計算機

身長(cm)と体重(kg)を入力すると、BMI・肥満度判定・標準体重を表示するWebアプリです。
Git講座(マニュアル化動画)の教材として使用しています。

## 使い方

`bmi-calc.html` をブラウザで開くだけで動きます(サーバー不要)。

1. 身長をcm単位で入力(例: 170)
2. 体重をkg単位で入力(例: 60)
3. 「計算する」ボタンを押す(入力欄でEnterでも可)

## 計算式

- **BMI** = 体重(kg) ÷ 身長(m)²
- **標準体重** = 22 × 身長(m)² (BMI 22が最も疾病率が低いとされる値)

## 判定基準(日本肥満学会)

| BMI | 判定 |
|---|---|
| 18.5未満 | 低体重(やせ型) |
| 18.5〜25未満 | 普通体重 |
| 25〜30未満 | 肥満(1度) |
| 30〜35未満 | 肥満(2度) |
| 35〜40未満 | 肥満(3度) |
| 40以上 | 肥満(4度) |
